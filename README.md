# 坦克大战 · Tank Battle

一个用原生 HTML5 Canvas + JavaScript 写的经典坦克大战（Battle City 风格）小游戏。

**整个游戏就是一个 `index.html` 文件，零依赖、零构建、零外部资源** —— 双击即玩，也可以直接丢到 GitHub Pages 上。

---

## 🎮 玩法

守住屏幕底部的**老巢（金色鹰徽）**，消灭全部敌方坦克。老巢被摧毁，或生命耗尽，游戏结束。

### 操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` / `↑` `←` `↓` `→` | 移动 |
| `空格` / `J` / `K` | 开火 |
| `P` / `Esc` | 暂停 / 继续 |
| `M` | 静音开关 |
| `回车` | 开始 / 重开 |

手机上会自动显示虚拟方向键和开火按钮。

### 地形

| 外观 | 类型 | 坦克能否通过 | 子弹能否穿过 |
| --- | --- | --- | --- |
| 🧱 红砖 | 砖墙 | ❌ | ❌（可击碎） |
| ⬜ 钢板 | 钢墙 | ❌ | ❌（需 3 级火力才能击穿） |
| 🟦 水面 | 河流 | ❌ | ✅ |
| 🟩 草丛 | 灌木 | ✅ | ✅（**会盖住坦克，可以埋伏**） |

### 敌方坦克

| 颜色 | 型号 | 特点 | 分值 |
| --- | --- | --- | --- |
| 🔴 红 | 普通 | 均衡 | 100 |
| 🟡 黄 | 快速 | 移动极快 | 200 |
| 🟣 紫 | 火力 | 子弹速度快、射速高 | 300 |
| 🔵 蓝 | 装甲 | 需命中 3 次 | 400 |

每隔 5 台会出现一台**红框闪烁**的坦克，击毁它会掉落道具。

### 道具

| 图标 | 效果 |
| --- | --- |
| ★ | 火力强化：1 级加速子弹 → 2 级双发 → 3 级击穿钢板 |
| ⛨ | 护盾 10 秒无敌 |
| ✸ | 全屏轰炸，清掉场上所有敌人 |
| ♥ | 生命 +1 |

> 阵亡后火力等级会清零，护盾和生命则保留。

## 🚀 运行

**方式一：直接打开**

双击 `index.html` 即可，不需要任何服务器。

**方式二：本地起个服务**（可选）

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

### 部署到 GitHub Pages

仓库推送后，在 GitHub 上进入 **Settings → Pages**，把 Source 设为 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存即可。

几分钟后就能通过 `https://<你的用户名>.github.io/<仓库名>/` 在线玩了。

## 🗂 项目结构

```
tank-battle/
├── index.html    # 全部内容：结构 + 样式 + 游戏逻辑
├── README.md
└── LICENSE
```

游戏逻辑在 `index.html` 底部的 `<script>` 里，按区块组织：

| 区块 | 内容 |
| --- | --- |
| 常量 / 网格 | 格子尺寸、地形与方向枚举、三关地图 |
| 音效 | 用 Web Audio API 现场合成的音效，**不含任何音频文件** |
| 碰撞 | 网格碰撞 + 坦克矩形碰撞 |
| 移动 | 带正交轴自动吸附的移动，转角不会卡墙 |
| 子弹 | 分步推进（防穿透），处理地形 / 坦克 / 子弹对撞 |
| 敌人 AI | 方向倾向 + 对齐开火 |
| 绘制 | 全部用 Canvas 图形绘制，**不含任何图片资源** |

## ⚙️ 想改点什么

- **改地图**：编辑 `LEVELS` 数组，每关 20 行 × 20 字符。
  `.` 空地 · `#` 砖墙 · `@` 钢墙 · `~` 河流 · `*` 草丛
  （老巢位置固定在下方中央，会自动生成，不用手写）
- **改难度**：`WAVE_PLAN` 控制每关敌人组成与数量；`G.maxOnScreen` 控制同屏上限；`ENEMY_TYPES` 调整每种敌人的速度、血量、分值。
- **加关卡**：往 `LEVELS` 和 `WAVE_PLAN` 里各加一项即可，通关判定会自动跟着变。
